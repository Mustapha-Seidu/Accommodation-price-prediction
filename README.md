# Accommodation-price-prediction using multiple variables

## The prediction model is divided into three.
1. Nightly price prediction model
2. Monthly price prediction model
3. Student hostel price prediction model

This is particularly important since, their have different pricing structure.

## Working on the 'Nightly price prediction model' first

#### Input features
1. price_per_night
2. parking
3. city
4. region
5. neighborhood
6. wifi
7. age
8. air_condition
9. fan
10. furnished
11. swimming_pool
12. currency
